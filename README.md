A summer project I did involving OOP and tkinter that allows for a user to have saved a JSON file containing words in the format "Hiragana", "Romaji", "English" & "Difficulty" (which has a value from 1-3). <br>
Two modes: multiple choice where there is a choice of using English or Japanese as the given term or pair matching. <br>
Can be played either in terminal or tkinter GUI (involves commenting out the unused function).
